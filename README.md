# Система учета оценок студентов (двумерные массивы)

Задание №4: работа с динамическими двумерными массивами (матрицами).

## Возможности
- Выделение памяти под двумерный массив (int**)
- Заполнение матрицы через std::cin
- Красивый вывод с рамками и заголовком
- Параметры по умолчанию в функции printMatrix
- Корректное освобождение памяти (сначала строки, потом массив указателей)

## Требования
- Компилятор с поддержкой C++14
- Стандарт: **C++14**

## Сборка и запуск
Команда компиляции: g++ -std=c++14 -O2 -Wall 1_4_laba.cpp -o 1_4_laba.exe
Запуск: .\1_4_laba.exe

## Ключевые моменты
- int** allocateMatrix(int rows, int cols) - выделение памяти
- void fillMatrix(int** matrix, int rows, int cols) - заполнение
- void printMatrix(...) - вывод с параметрами по умолчанию
- bool showBorders = true - показывать рамки из * и -
- std::string title = "Matrix" - заголовок по умолчанию
- void freeMatrix(int** matrix, int rows) - освобождение памяти
- Сначала удаляем строки (delete[] matrix[i]), потом массив указателей (delete[] matrix)
